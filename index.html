Python for Engineers

An introductory Python course with an engineering focus. Pick your week.

WeekTopicLab
1Python Basics: Expressions, Variables, and UnitsOhm's law and power calculator with resistor networks, an LED resistor, resonance, and a voltage divider.
2Data Types, Strings, Input, and Unit ConversionA unit converter that cleans sensor labels, formats tables, reads input, and catches a Mars Climate Orbiter style mismatch.
3Booleans and Conditionals: Thermostats and Safety InterlocksA thermostat with hysteresis, battery status ladder, input validation, and a machine safety interlock.
4Loops: Projectile Tables and Trial-and-Error DesignA projectile motion table and a launch-angle search, plus loop exercises for energy, halving, power tables, and component combinations.
5Functions and Modules: A Reusable Resistor LibraryBuild and test a resistor and circuit function library: Ohm's law, series and parallel, dividers, RC cutoff, percent error, and an LED resistor with assertions.
6Lists, Tuples, and Dictionaries: Sensor Log ProcessingA sensor log processor that cleans bad readings, converts units with comprehensions, applies calibration, and summarizes each sensor.
7Files, CSV Data, and Exceptions: Cleaning a Sensor FileA sensor file cleaner: read a file, parse CSV, convert safely, record bad lines, write a summary, and handle a missing file.
8Debugging, Testing, and Midterm ReviewA debug-the-bug challenge: fix six broken functions using tests, then add edge-case asserts to a function you write.
9NumPy Arrays: Vectorized Engineering CalculationsVectorized engineering calculations: power tables, quadratic roots, sensor spike removal, RMS of a waveform, a sensor matrix, and a loop-free projectile.
10Matplotlib: Plotting Engineering DataPlots with labels and legends: a power curve, a labeled sine wave, the RC charging curve with 95 percent time, two capacitors compared, a two-panel figure, and a beam deflection curve.
11Pandas: Tables of Engineering DataA multi-sensor log: load the table, select and filter, add a power column, compare sensors with groupby, repair a missing reading, and plot the temperature rise.
12Numerical Methods: Roots, Linear Systems, and Curve FitsWrite bisection, solve the diode voltage, solve mesh currents, build a truss solver, calibrate a sensor, and integrate a power curve.
13Simulation and Monte Carlo: Engineering with UncertaintyDice probabilities, pi by Monte Carlo, a divider tolerance study, an Euler cooling function, a moving-average filter, and a parallel reliability estimate.
14Classes: Modeling Parts, Batteries, and ControllersBuild a Resistor class, a Battery class, a series and parallel calculator, a sensor family, a thermostat, and a DC motor model.
15Capstone: Requirements, Structure, Self-Checks, and Final ReviewA battery discharge analyzer from requirements to tests: input validation, a model class, loading with pandas, a ranked plot, a Monte Carlo pack estimate, and a test suite that catches buggy code.
